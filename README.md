# 溫和風格網頁計算機

這是一個使用 **HTML、CSS、JavaScript** 製作的擬真網頁計算機最終版。  
新版移除角度模式與三角函式相關功能，也移除頁面介紹區塊，讓畫面直接聚焦在計算機與歷史紀錄。

## 專案檔案

```text
calculator_soft_version/
├── index.html   # 網頁結構與按鍵配置
├── style.css    # 溫和配色、擬真外觀、響應式版面與按鍵動畫
├── script.js    # 計算邏輯、事件處理、錯誤處理與歷史紀錄
└── Readme.md    # 使用與維護說明
```

## 功能特色

### 基本計算

- 加法 `+`
- 減法 `−`
- 乘法 `×`
- 除法 `÷`
- 次方 `xʸ`
- 等號計算 `=`
- 小數點輸入
- 正負號切換 `±`
- 百分比 `%`
- 倒退刪除 `⌫`
- 清除輸入 / 全部清除 `C / AC`

### 進階計算

- 平方 `x²`
- 平方根 `√x`
- 常用對數 `log`
- 自然對數 `ln`
- 倒數 `1/x`
- 圓周率 `π`

### 操作體驗

- 支援連續計算，例如：`2 + 3 × 4 =`
- 支援重複等號，例如：`5 + 2 = = =`
- 顯示目前算式與最後結果
- 保留最多 8 筆計算歷史
- 除以零、負數開根號、非正數對數等狀況會顯示錯誤訊息
- 按鈕具備擬真按壓動畫
- 支援桌機與手機瀏覽器的響應式版面

## 鍵盤快捷鍵

| 鍵盤 | 功能 |
|---|---|
| `0-9` | 輸入數字 |
| `.` | 小數點 |
| `+` | 加法 |
| `-` | 減法 |
| `*` | 乘法 |
| `/` | 除法 |
| `^` | 次方 |
| `%` | 百分比 |
| `Enter` 或 `=` | 計算結果 |
| `Backspace` | 刪除最後一位 |
| `Escape` | 清除 |

## 使用方式

1. 將 `index.html`、`style.css`、`script.js` 放在同一個資料夾。
2. 直接用瀏覽器開啟 `index.html`。
3. 使用滑鼠、觸控或鍵盤進行計算。

## 本版調整重點

- 移除角度模式切換。
- 移除三角函式按鍵與對應程式邏輯。
- 移除網頁介紹文字區塊。
- 將原本較強烈的配色改為米色、柔橘、灰藍與鼠尾草綠，整體視覺更溫和。
- 保留 v1、v2、v3 已完成的核心功能，包含四則運算、小數、錯誤處理、進階計算與連續計算。

## 開發說明

### HTML

`index.html` 負責建立頁面結構，包含：

- 計算顯示區
- 進階功能鍵
- 主要數字與運算按鍵
- 計算歷史列表

按鍵使用 `data-*` 屬性標示用途，JavaScript 會透過事件委派統一處理按鍵行為。

### CSS

`style.css` 使用 CSS 變數管理配色與陰影。  
主要設計方向如下：

- 背景使用低飽和漸層
- 計算機外殼使用柔和米色
- 運算鍵使用柔橘色
- 功能鍵使用鼠尾草綠
- 工具鍵使用灰藍色
- 按鍵具備輕微陰影與按壓動畫

### JavaScript

`script.js` 使用 `Calculator` 類別集中管理狀態與行為，包含：

- 目前輸入值
- 第一運算元
- 運算符號
- 是否等待第二運算元
- 最後一次運算
- 錯誤狀態
- 歷史紀錄

這樣能降低全域變數與 inline event handler 的依賴，使程式較容易維護與擴充。
